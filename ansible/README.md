# Ansible

Installs nginx and deploys the locally-built `dist/` (see `make build`) as
a static site on the host `../terraform` provisioned. `inventory.ini` here
is generated by `terraform apply` (see `terraform/inventory.tf`) — don't
edit it by hand, it's gitignored.

```
ansible-galaxy collection install ansible.posix   # once, for the rsync module
make build                                        # produces ./dist
ansible-playbook -i inventory.ini playbook.yml
```

`roles/webserver` does the actual work; `manual_webserver.sh` is the same
steps as plain shell commands, for reference.
